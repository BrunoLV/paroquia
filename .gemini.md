# Regras de Governança do Projeto Paróquia (.gemini.md)

Todas as diretrizes de arquitetura, padrões de código (Java/React), regras de LGPD, políticas de qualidade e comandos de ferramentas estão centralizadas para garantir paridade entre todos os agentes de IA operando neste repositório.

**Ações Obrigatórias e Inegociáveis:**
1. Antes de analisar código, propor soluções ou gerar qualquer arquivo, você DEVE LER o arquivo `AGENTS.md` localizado na raiz deste monorepo.
2. Você DEVE cumprir a regra mandatória permanente `.agents/rules/fluxo-desenvolvimento.md` e a skill `.agents/skills/fluxo-desenvolvimento/SKILL.md`:
   - No modo Plan: Consulta prévia a `docs/business-rules/<modulo>.md` e aprovação obrigatória do plano.
   - Na Execução: GitHub Flow (branch a partir de `master` atualizada), atualização obrigatória de `docs/business-rules/`, pergunta sobre encerramento de versão, registro em `CHANGELOG.md` e PR para `master`.

👉 **Leia `AGENTS.md` agora para carregar seu contexto operacional.**
