# Product Guidelines

## UI Theme & Aesthetics
- **Modern & Engaging:** The interface should feature subtle animations, a clean and angulated square design system (0px border radius), and vibrant accents to create an appealing and contemporary look.

## Tone of Voice
- **Concise & Action-oriented:** Use short, clear labels and focus on enabling users to get things done fast without unnecessary text.

## UX Principles
- **Efficiency First:** Optimize for power users with keyboard shortcuts, bulk actions, and appropriate data density.
- **Clear Navigation:** Ensure easy discovery with prominent sidebars, breadcrumbs, and logical hierarchies.
- **Error Prevention:** Use confirmation dialogs for destructive actions, clear validations, and safe defaults to prevent mistakes.

## Accessibility
- **Standard WCAG 2.1 AA:** Ensure general compliance for typical users, including proper contrast ratios, alt text for images, and semantic HTML structure.
